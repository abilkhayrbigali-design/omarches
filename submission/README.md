Быстрая проверка в пять шагов на сайте описана в начале `README.md` в исходниках. Для проверки диктовки и создания записи распакуйте исходники и запустите `python3 server.py`. Настроение дня описывают восемь чисел: с ключом OpenAI запись читает языковая модель, без ключа числа и название папки даёт встроенный словарь. От этих чисел зависят оформление сцены и всего сайта. На втором шаге можно загрузить фото, создать иллюстрацию по рассказу или совместить эти кадры. Для новых иллюстраций нужен серверный ключ OpenAI с оплатой запросов. Подключите его в корне проекта через `python3 server.py --set-image-key` или задайте переменную окружения `OPENAI_API_KEY` перед запуском сервера. На шаге с кадрами автор может изменить описание, заполненное текстом записи. По нажатию кнопки создания сервер отправляет OpenAI выбранное описание и стиль. Для проверки со своими фотографиями ключ не требуется. Подбор музыки из Openverse и воспроизведение выбранного онлайн-трека требуют интернета. Для озвучки нового дня доступны пять нейросетевых голосов после установки командой `python3 tools/install_voice.py`. В демонстрационных примерах дорожки уже подготовлены. Примеры открываются из распакованных папок двойным щелчком по корневому `index.html`.
