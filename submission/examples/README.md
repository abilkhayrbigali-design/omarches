# Шесть дней в «Оттиске»

Откройте `archive.jpg`, чтобы увидеть записи рядом. Шесть JPEG показывают сцены с названиями и числами настроения, которые дала модель при чтении записей. Для воспроизведения распакуйте `ottisk-examples.zip` и откройте корневой `index.html`. Архив содержит автономные HTML-сцены со звуком и исходными файлами.

| Файл | Название папки | Что ведёт день |
|---|---|---|
| `maple.jpg` | Какао под осенним клёном | Тепло и покой |
| `office.jpg` | Неон на офисном стекле | Напряжение и уединение |
| `train.jpg` | Розовый рассвет в поезде | Радость и покой |
| `rain.jpg` | Открытая книга под дождём | Покой и тишина |
| `lake.jpg` | Туман над горным озером | Покой и уединение |
| `cake.jpg` | Свечи на кухонном торте | Праздник и радость |

Три снимка показывают, как вместе с днём меняется весь сайт.

| Файл | Что на нём |
|---|---|
| `site-archive.jpg` | Главная страница: последняя запись, оттиск и числа всего дневника, архив |
| `site-day-office.jpg` | Страница напряжённого дня: сетка, рубленый шрифт, прямые углы |
| `site-day-cake.jpg` | Страница праздничного дня: тёплый фон, световые следы, крупный заголовок |

В папке также сохранены два исходных кадра из предыдущих версий прототипа.

- Модель DreamShaper 8 LCM создала акварель по рассказу об осенней прогулке. [Кадр из прежней видеодемонстрации](generated-illustration.png)
- Анонимная очередь AI Horde вернула облачную иллюстрацию размером 512 × 512. [Лодка на горном озере](aihorde-lake.webp)
